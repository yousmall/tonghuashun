# 对话与投资逻辑链

投资问答的助手消息仅展示「分析结论」和「风险结论」。重要的价格、集中度、流动性等投资风险、收益不保证、示例数据以及需要复核/已拦截状态保留在风险结论中。数据时点、范围说明、分析过程、引用原文、图表与情景分析、核验、人工复核、完整研究报告及 PDF 导出统一放在消息之外的投资逻辑链。

研究结论直接评价信号的性质、强弱、范围或实际意义，不罗列推导数据和判断限制。关键指标、所属期、支持或反面证据及判断限制在逻辑链中查看，原始数值和来源可继续下钻。明确询问某个数值时，可以直接给出该数值。旧回答的正文会折去带明确标签的证据和限制段，投资逻辑链仍保留原始内容。

每个对话 ID 对应一个逻辑链面板。同一对话继续提问时，追加咨询轮次并自动选中最新一轮；用户可切回此前任意已加载轮次查看对应的原始分析包。概要升级为完整报告时更新该轮内容。尚未返回结果的问题也会先进入逻辑链，显示等待状态。链内容由当前对话消息恢复，不再从其他对话寻找可用回答，也不自动混入演示数据。

新建对话后使用新的对话 ID，逻辑链为空；恢复历史对话后从该对话的消息重建。如果历史消息尚未全部加载，点击「加载更早消息」后会补入更早轮次。五个研究方向仍保留各自的对话状态。

入口在投资问答当前对话上方，展开「投资逻辑链 · 逐级展开与数据溯源」，选择咨询轮次。先展示四层证据下钻，再展开「完整分析、图表与报告」查看其余内容。补查资料的操作也在对应轮次内。历史咨询页面使用相同组件。持仓诊断与自选对比的独立结果使用各自的逻辑链入口。

投资工作台页面、首页与侧栏入口以及 `/api/v1/investor/*` 专属接口已移除。旧浏览器会话保存的工作台导航会转到主页。未删除账号历史资料；其他功能仍使用的选股偏好、持仓约束和费用复盘计算迁至 `backend/app/services/investment_support.py`，交易画像复盘展示迁至 `frontend/trade_review.py`。

验证使用离线分析包与 Streamlit AppTest，覆盖结论消息布局、轮次追加/切换、概要更新、新建/恢复对话、缺资料等待状态、详情与导出的位置、已移除入口及接口、共用交易画像与选股计算。未改变后端研判公式与对话持久化格式。

逻辑链及RAG/压缩/完整报告面板按对话与轮次单独保存展开状态，条件渲染清理控件后恢复；用户主动收起或代码主动打开仍优先。退出账号时一并清理，避免跨账号继承面板状态。
