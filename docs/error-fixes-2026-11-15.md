# 测试发现问题的修复与复测

日期：2026-11-15。基于合并提交 `c2b5018`，本轮修改保留在本地工作区。

## 修复

1. 图表初始化警告。最小应用使用有效的三行数据也能复现 `Infinite extent`，对应 [Streamlit #16614](https://github.com/streamlit/streamlit/issues/16614)。旧路径先创建空的 Vega 视图，再填入单独传输的数据。新增 `frontend/charts.py`：将小型图表的数据保留在图层内，让第一次绘制就能取得数据；使用公开 API，没有修改安装包、全局数据转换器或屏蔽日志。保留配色、均线、图例、缩放选择及图表导出；原页面表格继续提供数据浏览和下载。图表内嵌数据的方式不提供原 Arrow 数据源专用的“Show data”入口。
2. 无效数据不再直接绘图。空数据、无效日期、NaN/Infinity 和不足两个点的折线显示明确提示；过滤只发生在显示层，原始资料不被修改，不补零。基金收益走势、指数、研究对比、持仓、报告和管理统计图均接入同一渲染入口。
3. 减少快速模式的突发限流。独立的 lite/instant 队列由50毫秒调整为默认750毫秒，仍最多同时运行16个请求。新的环境变量为 `WENCE_LOCAL_RESEARCH_MAX_CONCURRENCY` 和 `WENCE_LOCAL_RESEARCH_QUEUE_SECONDS`，已加入 `.env.example`。原深度研究并发限制、适当性核验、账号隔离和2.6秒快速响应超时保留。
4. 保持启动轻量。图表模块的 pandas/Altair 改为按需导入，前端初始导入检查通过。
