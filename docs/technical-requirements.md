## 本次补齐的功能

1. 核验和合规节点执行总超时；抛错/超时返回 `REVIEW`，保留故障节点状态，撤下未通过完整审核的观点、分数、引用与配置建议。核验失败时合规显示跳过。
2. 数据能力总预算默认30秒，包含排队与重试。单能力超时记为失败，其他能力的成功事实继续保留。配置名：`WENCE_DATA_CALL_TIMEOUT_SECONDS`。
3. `GET /api/v1/metrics` 的 `analysis` 分组统计分析处理次数、失败、PASS/REVIEW/BLOCK、3秒内完成数、P50/P95/P99及最大延迟；包含取数/模型/核验/对话保存，不含前置鉴权及网络。全部HTTP指标在最后一块正文完成后记录，包含前置鉴权和流式发送。客户响应时间在100账号工具中从发起请求到收到完整结果测量。进程内成功率不能作为长期SLA。
4. 当前回答包含实际阶段耗时；流式取消会取消并等待后台任务，避免客户端退出后遗留分析任务。
5. 协作依赖/完成状态表、历史节点依赖保存、派生原始输入溯源。
6. 可复现100账号隔离验收、合成演示页、少量真实数据探针和可用性采样工具。

## 向别人演示：建议10分钟流程

正式页面 `http://localhost:8501` 使用原有普通账号登录，在“投资偏好”完成并确认测评。

1. **2分钟展示模型研究**：进入市场/行业/个股研究，输入具体对象与问题，展示返回的结论、风险和资料日期。
2. **3分钟展示解释与协作**：展开“分析过程与分项依据”，说明并行步骤、核验依赖、观点引用、结论失效条件；打开新闻或研报的原文链接。
3. **1分钟展示对话**：使用“它”“继续比较风险”等追问，再展示历史恢复。不要以未确认偏好绕过画像流程。
4. **2分钟展示安全边界**：使用独立合成验收页展示过期证据、同项冲突和收益保证拦截，避免人为改动真实用户数据。
5. **2分钟展示指标**：展示本次100账号验收、真实模型/数据报告和API咨询指标，同时明确3秒/生产并发/长期可用性的未达标或未验证范围。

单独的合成验收页不写入正式用户数据库，也不会调用真实模型或市场数据：

```powershell
.\.venv\Scripts\python.exe scripts/verify_requirements.py
.\.venv\Scripts\python.exe -m streamlit run frontend/requirements_demo.py --server.port 8502
```

浏览器打开 `http://localhost:8502`。选择市场、行业、个股、基金或组合场景；展开过程与来源；然后切换“过期证据演示”“同项冲突演示”“保证收益演示”。页面始终标明合成测试，可下载验收JSON。不得将这些合成结果用于真实投资。

接口层可打开 `http://localhost:8000/docs`，通过 `readiness`、`metrics` 和分析响应中的 `task_plan` / `facts` / `timings_ms` 说明代码证据。

## 仍需目标环境完成的验收

- **生产100用户**：使用100个独立真实普通账号、生产等价数据库与部署，覆盖浏览器会话、模型排队、上游限流、失效/重试和历史写入；测完整回答，不以占有100个租约代替咨询吞吐。
- **完整回答3秒**：当前真实完整流程实测5.751秒，至少需要降低串行模型调用耗时和外部取数耗时，并取得足够并发配额。默认模型并发5，只有一个进程的会话状态；不能直接增加worker而忽略租约与微信状态的进程内存边界。压缩预算让请求更快降级也不能证明有效投研回答达标。
- **源数据秒级**：记录上游原始报价时间、接收时间和展示时间，明确休市与非交易时段、供应商订阅更新频率；当前采集时间不能充当上游产生时间。
- **长期99.9%**：先确定统计窗口、完整咨询可用判据及计划维护口径，再做负载均衡/健康摘除、持久会话、数据库可恢复性、部署恢复和持续端到端观测。当前单机探针与重试措施不等于高可用部署已经完成。

这些运行指标本次保留为“未达标/未验证”，没有通过修改阈值、跳过事实核验或将进度包当作答案来宣称完成。
