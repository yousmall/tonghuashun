# 账号个人设置

侧栏 Logo 缩小，账号卡位于 Logo 下方，在最近咨询之前显示头像、昵称、登录账号和风险评估状态。点击“个人设置”可修改展示名称并上传 PNG、JPG 或 WebP 头像。头像最大 2MB，边长不超过 4096 像素；服务端校验实际图片格式、处理方向并裁为 256×256 的 PNG。

未设置昵称时，名称为“用户”加 8 位数字和字母混合字符。默认名称对同一账号保持稳定，新注册账号和旧账号都适用。展示名称与登录账号分开；修改昵称不影响原来的账号密码。昵称留空后保存可恢复默认名称；勾选“恢复默认头像”后保存可移除自定义头像。

资料保存到独立的 `user_appearances` 表，后端启动时自动创建，不需要修改旧的 `users` 表。`GET /api/v1/auth/me` 和登录响应返回 `display_name`、`avatar_data`；`PATCH /api/v1/auth/me` 仅更新当前认证账号的这两个字段，省略字段保持原值，传空值恢复默认，不接受用户标识或权限字段。

侧栏和风险评估结果卡共用账号头像；没有上传时使用本地默认头像，无外部图片请求。退出时清理个人设置控件及上传状态，重新登录从账号资料恢复。

自动投资规划、个性化投资建议与资产配置集中在侧栏“投资规划”页面；“风险评估”保留问卷、结果、评级依据及交易行为画像。
