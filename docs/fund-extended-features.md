# 基金未完成项补齐记录

2026-11-15。本轮补齐重仓证券、债券明细、完整公开行业配置、同类均值与排名，以及1/3/5年复利表现和统一口径风险对比。

## 页面入口

“投资问答 → 基金筛选”输入基金名称或代码。四个标签页分别为“收益与风险”“概况与费率”“持仓与配置”“长周期与对比”。

- “收益与风险”新增基金、同类平均、基准的阶段表现，以及各区间同类名次和样本总数。近3年网站公布收益也已接入，不再只使用问财区间值。
- “持仓与配置”展示逐只重仓股票和债券的名称、代码、占净值比例；各自保留披露期。新增完整的来源网站行业列表，包含零占比项，不用前十大持仓推算整体行业配置，不强制将占比归一化为100%。代码未在来源提供时标记“未提供”。
- “长周期与对比”支持选择1–4只基金，输入代码或名称，选择近1、3、5年窗口及假设年化无风险利率，点击“计算长周期收益与风险”。输出共同区间内的复利收益、年化收益、最大回撤、年化波动率、夏普比率和起点100的对比曲线。

## 数据与计算

重仓、同类平均和排名来自各代码的[天天基金详情](https://fund.eastmoney.com/510300.html)。行业及补充债券代码来自[同花顺基金投资组合](https://fund.10jqka.com.cn/510300/portfolioindex.html)。所有记录保留来源、基金身份、净值日或披露期；来源不可用时各栏目独立降级。

长期计算读取天天基金公开单位净值和日增长率序列。普通日以同源相邻净值之比保留精度；分红、份额折算日沿用`equityReturn`披露增长率，再按`W[t] = W[t-1] × (1 + r[t])`逐段复利连乘。不以整个窗口的单位净值或累计净值首尾比值冒充复权回报。这里是理论分红再投资假设，不包含申赎费用与税费。事件日增长率仍可能有舍入误差，与网站直接公布值可能略有差别。此精度优化及五类基金最新核对见[完整测试与网站对照](fund-validation-2026-11-15.md)。

各基金先在自身完整序列上计算复利指数，再对齐共同日期，避免漏掉某个市场独有交易日的收益。输出实际共同起止日，不将历史较短的基金自动当作完整五年。数据不足、长缺口或无法解释的净值/增长率差异均不给出风险结果。

年化收益采用实际日数365.2425换算；波动率采用共同观测收益的样本标准差并按252个观测年化。夏普采用相同年化无风险利率换算出的每期利率及算术超额收益；零波动时夏普显示缺失。最大回撤在共同观测日期上计算。所有份额按自身原计价币种，未做汇率换算；比较时应选择相同币种份额。

该计算统一的是本项目内的窗口和假设，不把网站、问财中未披露计算参数的夏普比率混在一起排序，也不保证与某个网站四舍五入后的风险指标逐位一致。

## 接口和性能

新增登录后只读接口`POST /api/v1/data/fund-analytics`：

```json
{"targets": ["510300", "000001", "110011"], "years": 3, "risk_free_rate": 2}
```

最多四只，名称/代码每项1–60字，禁止重复项，年份限定1/3/5，无风险利率限定0–20%。名称解析成同一份额时明确提示。长期原始日序列只供本接口使用，不塞入普通问答证据包。沿用有界后台任务与300秒公开资料缓存，切换年份或利率可复用历史序列；页面会话只保存最多8组计算结果，退出登录时清理。
