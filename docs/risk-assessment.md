# 风险评估十九题问卷

侧栏只保留“风险评估”入口，使用十九题问卷。题目依据用户提供的方正证券截图，前端每次只在一个边框内显示一题；首次评估无默认答案，翻页保留选择，末题提交后核对并确认保存。结果页删除底部办理须知；点击“重新评估”可随时修改，默认恢复上次答案。

- 题目及选项来自用户提供的十九题截图。未取得官方登录后的完整测评页面，也未取得这版问卷的逐选项分值表。官网公开政策全文截图位于本地 `.tmp_flow/founder-matching.png`，分类说明页面截图位于 `.tmp_flow/founder-classification.png`。

## 后端与下游使用

- 新界面向 `/profile/assess` 发送版本及 `risk_answers`（`q01`–`q19` 的 A–E 选择），不调用语言模型评分。旧评估 API 暂保留兼容；确认 API 必须收到完整的新问卷。
- 服务端拒绝无效选项，未答完不评级；债务与偿债用途、投资年限与交易经历明显矛盾时不能确认。
- `/profile/confirm` 从答案重算分数、分类、日期和各项标签，忽略客户端改写的等级和有效期；保持已有仓位硬上限。
- 账号保存沿用现有版本检查和数据库事务，可在同一天多次重新评估并确认保存。重新登录恢复答案和结果；退出清理问卷状态。
- 档案保存每道题的可读题干及选择，供后续研究使用。C1–C5 是展示分类，内部兼容风险准入使用 R1–R5。
- 期限和投资经验保存原始区间；定性的损失承受程度保留文字。问卷未询问精确月数、亏损百分比和年化收益率，不推算这些数值。
- 过期问卷阻止新的个性化分析。基金候选同时核对风险等级、品种和期限，缺少核验资料时降级；仅选固收的画像不输出权益配置区间。
