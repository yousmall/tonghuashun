# 风险评估与财务规划二十七题问卷

侧栏只保留“风险评估”入口，使用二十七题问卷。前十九题依据用户提供的方正证券截图，后八题是本平台补充题。所有题目共用原来的边框、题号、A–E纵向单选、上一题/下一题和提交按钮；首次评估无默认答案，翻页保留选择，末题提交后核对并确认保存。点击“重新评估”可随时修改，默认恢复上次全部答案。

## 约束配置与假设情景

`backend/app/profile_guidance.py` 使用 `financial-constraints-v1` 平台规则。先按风险等级选基础权益区间，再按近期必要支出、应急储备、还款负担、收入稳定性、产品意向和最早用款期限收紧权益与流动性边界。没有风险等级时不填默认稳健档。

- 应急储备不足3个月：流动性底线30%，权益上限20%。
- 还款负担超过40%：流动性底线50%，权益上限20%；超过60%或收入无法覆盖还款时权益上限为0。
- 最早用款期限不超过1年：权益上限为0；不超过3年时上限30%。
- 本金安全优先不安排权益；不能接受回撤时按全额流动性预留，并明确产品不保证本金或零回撤。
- 对明确回撤上限，使用“权益跌20%、固收跌5%、现金及低波动类不变”的假设进一步收紧配置。第二情景使用40%、10%、0%的跌幅，超过用户边界时提示复核。

三类区间共同可行，示例配置合计100%；不能把三个区间的上限直接相加。示例用于说明约束，不是历史数据拟合的最优组合、具体交易指令或实际回撤保证。现金及低波动类的0%情景变化仅为假设，实际产品可能亏损、有赎回限制和费用。

本实现借鉴三个社区技能的公开功能范围，采用本地可审计规则；没有安装、调用或宣称验证了社区技能服务。具体产品和持仓分析仍走项目既有数据来源及事实核验流程。

## 旧问卷升级

旧版十九题答案保持不变。首次打开升级后的风险评估从第一道未答的补充题开始，允许返回修改旧答案。旧版档案在完成补充题并重新确认前不能用于新的个性化研究；不自动补选新增答案，不静默修改已存档案。新版本评估和确认均要求全部27题完整且一致。

## 后端与下游使用

- 新界面向 `/profile/assess` 发送版本及 `risk_answers`（`q01`–`q27` 的 A–E 选择），不调用语言模型评分。旧五维评估 API 暂保留兼容；确认 API 必须收到完整的新问卷。
- 服务端拒绝无效选项，未答完不评级；债务与偿债用途、投资年限与交易经历明显矛盾时不能确认。
- `/profile/confirm` 从答案重算分数、分类、日期、财务区间、回撤上限、流动性、解释、配置及情景测算，忽略客户端改写的派生值；保持已有仓位硬上限和用户明确约束。
- 账号保存沿用现有版本检查和数据库事务，可在同一天多次重新评估并确认保存。重新登录恢复答案和结果；退出清理问卷状态。
- 档案保存每道题的可读题干及选择，供后续研究使用。C1–C5 是展示分类，内部兼容风险准入使用 R1–R5。
- 期限和投资经验保存原始区间；定性的损失承受程度保留文字。问卷未询问精确金额、月数和年化收益率，不推算这些数值；第26题明确选择的回撤上限按原值保存。
- 过期问卷阻止新的个性化分析。基金候选同时核对风险等级、品种和期限，缺少核验资料时降级；仅选固收的画像不输出权益配置区间。
