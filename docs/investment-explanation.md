# 投资建议可视化与解释

三个需求共用同一份后端建议包，回答、历史详情和 PDF 采用同一口径。

| 图片要求 | 实现入口 | 演示方式 |
| --- | --- | --- |
| 分析过程与结论可视化 | `frontend/presentation.py` 的结论面板、阶段卡片与逻辑链；`frontend/investment_panel.py` 的价格情景图及资产区间图 | 在投资问答查看最新结果；在历史记录 → 分析详情查看四个结果页签 |
| 逻辑链逐级展开与数据溯源 | `render_logic_chain`、`source_trace_rows`、`render_source_trace` | 展开分析维度，查看观点、风险、失效条件、派生规则、原始输入及原文链接；数据溯源页支持按分析维度筛选 |
| 风险提示、收益预期、仓位建议 | `ReturnExpectation`、`build_return_expectation`、`render_investment_panel` | 结论面板始终展示风险、收益及仓位栏目；组合诊断有可靠引用及已确认风险等级时展示资产类别目标区间 |

## 收益预期口径

`AdvicePackage.return_expectation` 新增结构化结果，状态包括 `unavailable`、`scenario`、`blocked`。历史记录保存相同结果，旧记录兼容缺省字段。

- `user_goal_annual` 仅保存用户明确确认的期望年化收益，不是系统预测。
- `investment_horizon_months` 保存已确认期限，与目标价实现期限分别展示，不替代后者。
- `scenarios` 保存参考价、机构目标价、币种、价格情景空间、各自日期、期限说明和两个事实引用。
- 情景空间 = 目标价 / 参考价 - 1，未计分红、费用及税费。保留多份机构观点，负值正常展示；不从目标价推断实现概率、目标期限或年化收益。
- 仅使用核验后实际引用的事实。同一标的完整代码、显式币种及明确日期必须兼容；价格冲突、日期缺失、币种未知或不匹配、无效价格、未引用/过期目标价均不生成数值。抓取时间不充当行情日期或报告日期。
- 缺少预测依据时展示尚未形成可核验预测；合规拦截时不展示收益数字和配置区间。历史记录丢失情景依据时不恢复图表。

## 仓位口径

后端已有风险等级对应的资产类别区间，本次将其接入区间图、明细表、历史回放与导出，并保存支持组合诊断的事实引用。

未确认画像、风险等级未知、组合节点失败/未知或没有核验引用时，不使用默认 R3 配置。`REVIEW` 下仅展示配置研究思路并要求复核；`BLOCK` 下不展示区间。各类别区间不能直接相加，实际选定比例须合计 100%，并另行复核期限、流动性和集中度约束。

## Agent 按需自动取数

普通分析入口 `POST /api/v1/portfolio/analyze` 默认 `auto_fetch=true`。首次取数后，`recover_research` 会检查缺项，按服务端白名单选择更具体的问财能力：

| 缺项 | 按需能力 |
| --- | --- |
| 市场政策、风险偏好 | 官方政策资讯、上涨家数及总家数 |
| 行业景气、资金流向、拥挤度、政策 | 明确行业的营收指标、资金与成交额、历史换手率和源交易日历、行业政策原文 |
| 公司事件、治理 | 事件公告、审计/监管/披露资料；必要时最多读取本轮供应商返回的两份官方 PDF |
| 收益情景 | 明确标的的行情和机构目标价，保留币种、实际日期及原文 |

股票所属行业必须来自该股票的基础资料，不会用其他行业排名代替。首批基础资料才返回所属行业时，本轮可追加行业查询。一次补取最多 12 个供应商能力调用；每项都有超时，另最多读取两份官方 PDF，并只做一次带引用的定性评估。不运行任意模型提供的方法、URL 或交易工具。

政策、事件、治理的标签由现有语义评估能力产生，服务端逐项检查实体、原文引用、连续引文和完整评分口径后才能派生评分。缺少治理三项中的任何一项均保持缺失；模型不可用或没有原文时不填中性分。

价格与目标价的新 `observation_date` 保存实际行情/报告日期，`period` 仍保留文档记录标识，二者不会互相覆盖。收益面板使用的引用也进入同一个事实核验与合规闸门。

自动取得的公共事实沿用现有缓存。授权拒绝、能力无权限、额度耗尽均停止对应能力重试，其他已成功资料保留；审计保存查询结果、缺项、评估状态和耗时。关闭 `auto_fetch`、画像未确认或被拦截时不触发补取。

## 按需获取优化

- `research_requirements.py` 为服务端查询定义必需字段、实体、单位和日期要求。`capability_evidence` 与 `recovery_evidence` 区分 `complete`、`partial`、`returned`、`empty`、`failed`、`deferred`。原有 `successful_capabilities` 只表示接口返回了资料，不能作为某个评分或收益依据已经齐全的证明；没有必需字段的资料仍保留用于其他可核验维度。
- 缺流动性时单独获取中国 M2；缺市场广度时查询同一全 A 指数范围的上涨家数及总家数；行业查询明确同花顺指数口径、统计日期和单位，拒绝用成分股资料替代行业指标。目标价使用专门查询，保留有效行情，避免因目标价缺失反复刷新已有价格。
- 补取按照优先级分配总计 12 项能力预算。股票基础信息解析前预留五项行业查询位置；历史换手率及源交易日历作为不可拆分的依赖组安排。未执行的查询在审计中保留，不伪装成空结果。
- 政策、事件、治理按相关性和实际发布日期选择原文，同一记录的标题和摘要去重，PDF 各页独立保留。原文读取的实际日期从来源传递，资料不足或模型不可用时不生成中性评分。
- `WENCE_RECOVERY_TIMEOUT_SECONDS` 默认 45 秒，数据补取、PDF 读取、证据评估共同使用剩余时间；已成功的资料在其他调用超时后仍保留。该预算针对补取阶段，不是整次请求的响应时间保证。问财连接池与已有并发限制保持一致。
- `recovery_gap_metrics` 记录评分缺项前后数量、调用次数、延期数量及必需字段完成情况；历史记录保存这些审计字段。

## 2026-10-04 目标价、行业原始数据与公告正文补齐

- 机构研究改为简短的“证券代码 研报目标价”查询。实际接口同时返回目标价、币种、公告日期和研报链接。机构记录夹带的最新价不再采用研报发布日期作为行情日期，避免错误构造收益情景。
- 同花顺三级行业的“Ⅲ”分类后缀与同名 `.TI` 指数显示名称进行限定匹配，保留原来的行业实体；不混用申万等不同指数体系。行业资金查询取得主力净买入额、成交额、市盈率及市净率，并保留日期和单位。
- 行业接口未提供营业收入同比汇总值时，获取完整成分股在同一期和上年同期的收入，按 `(本期收入合计 / 上年同期收入合计 - 1) × 100` 计算。只有返回总数、唯一证券代码、准确行业归属、全部收入和明确单位一致时才生成。这是**当前成分股的收入汇总代理指标**，不是供应商直接公布的行业统计，不代表过去时点的成分股名单；所有名单及收入事实 ID 都保留在来源链中。
- 历史换手率按交易所源日历的真实交易日，以明确中文日期、每批十日请求。少量漏列最多补查三日一次；完整年度覆盖和同一指数验证通过后才生成历史百分位及拥挤度。日历查询由并行依赖共享同一任务，避免重复下载。12 项限制是业务能力预算，历史能力内部最多 27 批和一次小范围补查，真实网关请求数在探测的 `gateway_attempts` 中逐次记录；整体仍受补取时间预算及现有限流约束。
- 搜索资料优先解析 `stock_infos` 的证券身份和标题，不把混入的其他公司公告归到查询公司。仅官方允许域名的 HTTP PDF 链接可升级到 HTTPS。遇到非 PDF 校验页面或连接失败时，在巨潮官方检索中核对同证券、同标题、同中国时区发布日期的 PDF 原文，读取后再次核对文件内公司身份，并保留官方链接与页码。正文最多为每份六页的相关原文节选，不声称通读整份文件。
