# 投资工作台

入口：左侧“投资工作台”，或主页“打开投资工作台”。包含新手学习、偏好与当前持仓、交易复盘、教学模拟和决策记录五个工作区域。

## 新手使用

依次完成资金与风险核对、股票和估值基础、候选比较、教学模拟及复盘学习。引导按钮连接现有风险评估、投资问答和自选研究；知识练习区分交易经验与风险承受能力。

教学账户初始资金10万元，仅使用用户输入的假设价格与费用。练习采用100股整手和买入次日可卖的规则，检查现金、可卖数量、费用及日期顺序，禁止融资和卖空。交易由服务端重新记账，按账号保存，最多1000笔。它不模拟真实交易日历、涨跌停、停牌、盘口、排队成交、分红和公司行动，不连接券商或真实资金。

## 历史偏好与选股

先在风险评估上传并确认Excel交易报告，再进入工作台查看历史题材和持有期线索。题材可填入待确认草稿（斜杠分类取首个名称）；确认之前不参与筛选。用户应核对名称与数据源行业分类是否一致，并可修改、增加或排除行业。

确认后的偏好会用于真实选股流程：

- “优先研究”给已通过原有证据和风险核验的匹配候选最多5分排序加分，保留原研究分。
- “仅研究这些行业”和排除行业用于筛除不匹配候选。
- “短期观察”把候选日均成交额筛选底线提高到1亿元；这是平台研究规则，不是收益或流动性保证。
- 确定单次金额后，按自填佣金、最低佣金、卖出税费和双边滑点计算往返成本。高于用户确认成本预算时排除候选。显示费用门槛，不推算股票能够上涨多少。

历史行为不提高风险等级，也不替代资金用途、可接受损失和财务约束。资金约束不安排权益时不输出股票推荐。历史偏好不是经过回测验证的盈利策略。

## 当前持仓

按“代码,行业,市值”录入全部投资资产，另填现金、估值日期，并明确确认完整性。行业必须采用同一分类口径；无法分类时先补齐。

完整持仓下，新增金额上限取现金、单票剩余额度、行业剩余额度的较小值。计划新增金额超过额度或额度用尽时排除对应候选。估值超过7天时需要更新。不完整持仓不编造可买金额；它仍可用于研究，但不能当作已完成持仓适配。

额度按录入资产市值计算，落地时还须预留交易费用；不生成真实订单。这里的当前持仓与历史成交额占比分开，不能用历史成交额替代当前持仓。

## 费用复盘

工作台支持粘贴三类CSV：

1. 逐笔成交：日期、代码、方向（buy/sell）、数量、价格、该笔全部费用、行业。
2. 可选期初持仓：代码、数量、已含历史买入费用的单位成本、实际取得日期、行业。取得日期须早于第一笔成交；不同批次可分行录入。
3. 可选资产估值：日期、全部资产总值、观察期末净入金。首行作为基准，净入金须为0；只适用于明确发生在期末的现金流。

按先进先出匹配，买入费用按股数分摊，计算可完整匹配卖出的毛损益、净损益、逐股样本胜率及持有天数。费用缺失保留未知；缺少期初成本的卖出不宣称净损益完整。结果不包含未平仓损益、分红和拆并股，不能直接当作账户总收益。

提供完整资产估值和期末现金流后，可计算观察期间时间加权收益及观察点最大回撤。稀疏估值不代表逐日最大回撤，不凭成交买卖差额推算账户收益，不自动年化。

原有Excel逐笔导入新增可选“该笔总费用”（别名：总费用、交易费用合计、fee、totalfee）和“所属行业”列。总费用须包含该笔所有实际费用；系统不会把单独佣金误认为全部费用。画像仅保存复盘汇总，不新增持久化逐笔复盘原文。汇总报告仍标记为报告值，不能独立重建逐笔净收益。

## 决策记录与账号边界

记录证券代码、当时理由、失效条件、下一次复核日期及结果。可对同一股票追加观察，保留原理由；到期显示需复核标记，不创建后台提醒或自动交易。每账号最多1000条记录。

偏好、持仓、教学账户和决策记录按账号保存，沿用画像版本号进行乐观锁检查；旧页面提交返回409。重新确认风险问卷保留服务端工作台数据，不能通过客户端问卷伪造教学余额。退出清理全部`workbench_`会话状态。模型研究输入不包含教学流水和决策日志。

新增鉴权接口：`GET/POST /api/v1/investor/workspace`、`POST /api/v1/investor/review`、`POST /api/v1/investor/paper-order`、`POST /api/v1/investor/journal`。复盘接口只读，不保存原始CSV；写入接口要求`expected_version`，账号归属由登录上下文决定。
