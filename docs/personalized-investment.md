# 个性化投资建议与资产配置

入口：风险评估 → 个性化投资建议与资产配置。确认保存当前27题问卷后自动展示比例方案，也可填写本次投资金额，点击“生成个性化方案”换算三类资金金额。金额为0时仅查看比例；不从问卷金额区间猜测本金。

方案从原始问卷重算风险等级、必要支出、应急储备、负债负担、流动性、用款期限和回撤约束，复用 `profile_guidance.py` 的配置规则。相同风险等级也会因用款期限、负债等约束形成不同配置。提高收益目标不会提高风险额度，年化目标超过20%时另行提示复核。风险等级、产品风险和可接受回撤分开展示；假设情景不能保证真实损失不超过边界。

输出包括权益类、固收类、现金及低波动类的参考区间和合计100%的示例占比、明确本金下的参考金额、逐项建议及依据、两组明确标注假设的压力情景、人工复核与再平衡安排。金额使用最大余数法分配到分，合计等于输入本金。每3个月复核及偏离参考占比5个百分点时人工评估，是本功能的平台复核规则。

建议覆盖必要支出与应急资金、偿债、收入持续性、期限匹配、收益目标及集中度。已确认的交易分析可补充执行建议，交易额占比不作为当前持仓权重，也不反推风险承受能力。没有当前持仓与行情时，不输出具体证券买卖数量或市场收益预测。

## 账号与确认边界

登录后只读接口 `POST /api/v1/profile/investment-plan`，请求示例：

```json
{"investment_amount":"100000.01"}
```

金额可省略；有效范围为0.01至1万亿元，最多两位小数，拒绝非有限数。禁止额外字段，不接受客户端提交用户ID、画像、问卷或风险等级，画像仅从登录账号读取。资金金额必须处于已确认第20题的区间，按“不足”边界严格验证。

- `ready`：已确认且有效的当前问卷，信息可支持配置。
- `needs_assessment`：未确认、过期、旧版或不完整问卷，不返回配置。
- `needs_information`：最早用款时间未明确、本次金额与问卷区间不一致，或另有尚待兼容性复核的自定义限制，不返回配置。

接口不写数据库，不续期测评，也不调用模型或行情。每次从原始答案重新生成，不沿用存储的评级、配置或压力情景展示字段。保留原测评有效期及画像版本。文字自动规划仍为独立预览，不改写已确认方案。

前端在编辑问卷时隐藏方案，画像、日期变化时清理金额预览，退出登录沿用 `automatic_plan_` 前缀清理所有相关会话状态。提交失败时清除旧结果，服务端画像版本变化时提示刷新，避免将旧金额显示为本次成功结果。
