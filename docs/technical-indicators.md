# 六种技术指标

已接入 MACD、RSI、KDJ、BOLL、ATR、OBV，按趋势、动量、波动率和量能四类展示。它们属于历史走势观察，不改变原有中和评分，也不自动作为智能体投资结论的事实证据。

## 页面入口

- 个股研究、可转债分析：选定标的，展开「技术指标与完整走势」，点击「加载 / 刷新技术指标」。
- 基金筛选：同一入口，按单位净值计算 MACD、RSI、BOLL；净值没有日内高低价和成交量，KDJ、ATR、OBV 明确显示数据不足。
- 自选走势：点击「加载 / 刷新近 60 期走势」。
- 市场解读：主要指数看板中选择单个指数。
- 行业分析：选择行业并点击「加载 / 刷新行业走势」。

面板展示六张最新值卡片，四类切换后显示对应指标图、最新日期和全部分量。投资问答中不再展示计算口径、样本说明、重复走势描述及指数看板底部备注；自选走势等其他入口保留原有说明，计算口径继续保留在接口与本文中。展开各指标的「数据与下载」可查看逐日数据并下载 UTF-8 CSV。类别切换使用已取得的历史数据，不重复请求问财。指标曲线在缺失值处断开，预热期保留为空。

## 默认计算口径

| 指标 | 参数与初始化 | 最少样本 |
| --- | --- | --- |
| MACD | EMA12−EMA26 为 DIF；EMA9(DIF) 为 DEA；柱值采用国内常用的 2×(DIF−DEA)。各 EMA 由本次区间首值初始化 | 34 期收盘价 |
| RSI | 14 次价格变化的初始平均涨跌，再按 Wilder 的 1/14 权重平滑；无涨无跌为50、单边涨为100、单边跌为0 | 15 期收盘价 |
| KDJ | RSV 使用9期最高最低；K、D 初值50，按1/3递推；J=3K−2D，保留0–100以外读数；零振幅 RSV=50 | 9 期完整高低收 |
| BOLL | SMA20 ± 2倍总体标准差，ddof=0 | 20 期收盘价 |
| ATR | TR=max(高−低, abs(高−前收), abs(低−前收))；首14个TR取均值后按 Wilder 平滑 | 15 期完整高低收 |
| OBV | 区间首日0，上涨加当日成交量、下跌减当日成交量、平盘不变 | 至少2期收盘价，整个区间成交量完整且单位明确统一 |

EMA 和 OBV 依赖所加载区间的起点；MACD 初始化及柱值倍数也可能与其他软件的口径不同。本次加载近60期，显示的是该有限窗口的计算结果，不声称与券商全历史序列逐点一致。参考 [TA-Lib 指标目录](https://ta-lib.org/functions/)；本项目实际公式与初始化以本表和返回的 `method` 字段为准，未新增 TA-Lib 运行依赖。

## 数据与接口

`POST /api/v1/data/price-history` 保留原有登录鉴权和30/60期参数。`points` 新增可空的 `high`、`low`、`volume`、`volume_unit`；`analysis.indicators` 返回六个指标，每项包含 `available`、`latest_date`、`latest`、`series`、`parameters`、`method`、`unit`、`message`。旧响应不含指标时，前端仍可绘制原价格图。

新增 `get_technical_history` 使用同一次固定模板只读请求取得高低收与成交量，要求同一不复权价格口径。原 `get_price_history` 默认仍仅返回价格/净值，避免影响已有概览、组合分析等调用方。技术指标计算不消耗模型请求。

仅使用明确交易日期；未来日期、其他证券、同日同字段冲突剔除。高价低于收盘、低价高于收盘或高低价倒置时，高低价失效。KDJ、ATR 遇到缺失高低价后重新预热。成交量支持真实零值；股、手、份、张分别保留，万/亿倍数在同种单位内归一化。单位不明、混合股和手、缺失成交量时不计算 OBV，不用成交额代替。供应商未返回所需字段时，页面显示具体原因。

## 验证边界

`tests/test_technical_indicators.py` 使用合成数据与离线 MockTransport，覆盖公式参照、预热、因果性、缺失/冲突处理、成交量单位、API 序列化、指数合并、类别切换和按需取数。它们验证实现和接口契约，不证明当前问财账号的权限或真实返回字段完整。真实数据可用性以加载后的日期、读数和缺失提示为准。
