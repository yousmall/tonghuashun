# 关注标的分档与自选分页

2026-11-15。

首页“关注标的”按当前账号实际保存数量显示：0–29个为准确数量，30–49个为“30+”，50个及以上为“50+”。鼠标查看指标提示可见准确总数；数据尚未取得时仍显示“未取得”，不显示成0。“我的自选”标题和分页信息始终显示准确数量。本轮没有向实际账号添加示例证券。

账号自选容量由50扩到200个。“自选研究 → 我的自选”默认每页20条，可选10、20、30、50条，支持上一页、下一页和跳转页码。搜索名称或代码、切换类型和每页条数均回到第一页。新增后回到第一页，保留当前搜索和类型筛选条件；删除最后一页最后一条时，页码自动回到仍有记录的页面。详情和移除针对当前页；横向比较的2–4项选择可跨页保留。

行情接口`POST /api/v1/data/watchlist-quotes`新增可选`ids`，按传入顺序返回当前页自选行情，不再固定只查询最近20个。每次最多50个不重复的正整数ID，所有ID必须属于当前登录账号，已移除或其他账号的ID返回404。旧客户端不传ID时仍返回最近20个。读取不改变账号自选。

行情/财务资料最多同时加载8个标的，沿用公共缓存的并发与待处理上限。一次50项不会因自身同时提交100个栏目任务而挤满队列。页面使用后台加载，翻页后切换请求与快照签名，旧页结果不会显示到新页。大页行情请求采用240秒读取上限，其实际耗时取决于数据源与缓存；这不是加载时间保证。

专项验证使用57条模拟自选，覆盖3页翻页、30/50条每页、按名称搜索和类型筛选、当前页行情ID、跨页比较、末页删除、新增后回首页，以及200条账号持久化、容量边界、账号隔离和50项真实缓存调度。首页覆盖29/30、49/50边界、空列表与加载中状态，并实际验证指标显示和准确总数提示。

验证使用隔离SQLite、FastAPI TestClient与Streamlit AppTest，未改动真实账号数据或启动线上服务。最终全量结果见`.tmp_test/watchlist_final.xml`和`.tmp_test/watchlist_final.log`。

最终全量离线回归：**1124项通过，0失败，1条警告，135.13秒**；本轮新增21项专项测试。
