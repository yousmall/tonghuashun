# 风险偏好、收益预期与投资期限自动规划

2026-11-15。入口为“风险评估”页面的“自动投资规划”。

## 使用方式

完成现有27题问卷后，系统自动生成三项规划，不需要重复填写风险等级、收益目标或期限。确认保存后，规划随账号画像恢复；旧账号也会在读取时生成规划并重新检查测评有效期。

可在“描述您的投资计划”中输入一段话，再点击“自动识别并规划”，例如：

> 我偏好稳健，可投资资金20万元，计划投资3年，2年后买房，最多可接受回撤8%，期望年化收益8%。

在没有其他问卷期限约束时，这段描述识别为稳健倾向、可接受回撤8%、年化收益目标8%，按更早的2年用款时间安排。20万元按该目标复利两年的算术结果为233280元，差额33280元；页面明确标注这只是用户目标下的计算，未计税费。没有完整问卷时不会生成正式承受能力评级。

## 三项结果

- 风险偏好：优先记录文字中的明确偏好，问卷默认依据第14、15、26题的目标和损失偏好。偏好与整体问卷承受能力R1–R5分开展示，不能相互替代。零回撤、不同偏好并存及文字与问卷不一致会提示核对。
- 收益预期：保留第27题或描述中的收益目标区间，支持负数、区间、至少、不超过及无固定收益目标。明确本金、年化目标和精确期限时给出复利算术演示；本金、目标金额和精确期限同时明确时，反算一次投入、无追加资金条件下所需的年化收益。目标矛盾、较高收益与较低损失边界、金额或期限不匹配均提示复核。
- 投资期限：识别中文或数字年数、月份、半年、跨单位区间与用款时间。保留问卷约束，取有限期限上界中更早的约束安排；同一上界存在区间时保留区间。明确月数才生成日历日期，月底按目标月实际天数处理。区间、至少持有期和最早用款日未明的描述不生成虚构到期日。

时间表包括当前资金用途核对、每3个月复核、用款前流动性安排及明确的计划用款日。原文依据和缺失项可直接核对。描述识别支持上述明确表达；没有识别依据的内容会保留为缺项，不从风险等级猜测收益或期限。

## 数据与确认

新增登录后只读接口`POST /api/v1/profile/auto-plan`：

```json
{"narrative":"稳健，可投资资金20万元，计划投资3年，能承受回撤8%，期望年化收益8%。"}
```

描述最多2000字。可额外提交当前`questionnaire_version`和已答`risk_answers`预览编辑中的问卷。服务端验证版本、题号、选项和一致性，完整问卷才重算承受能力等级；部分答题不沿用旧评级。请求禁止提交用户ID、风险等级或伪造画像；已保存资料仅从当前登录账号读取。

文字识别结果为会话预览，不改写已保存的问卷、有效期或确认状态。问卷确认时在服务端重算自动规划，忽略客户端伪造的规划结果。过期测评不会因预览自动续期。退出登录清理预览及原文，编辑答案后清理旧预览。计算采用本地确定性规则，不调用大模型或行情接口；模型研究输入沿用原始问卷、目标区间和财务约束，避免重复发送展示用规划。
